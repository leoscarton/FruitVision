# Fruit Vision

This is a WIP project designed to detect and correctly name and count fruits in video frames. The initial goal is to make it able to handle both recorded videos and live cameras. The project focus is on tropical fruits.

## Architecture

### Back-End

- Language: Python 3.14.7 (Subject to change)
- Main Computer Vision Library: OpenCV-Python 5.0.0.93
- Machine Learning Computer Vision Framework: TorchVision (subject to change, version will be announced in the future)

### Front-End

- Language: TypeScript 7.0.2 (Subject to change)

Further details will be announced soon.
